## โครงงานนี้ทำอะไร

นำข้อมูลสถิติการส่งออกสัตว์น้ำของกรมประมง พ.ศ. 2563–2567 มาสร้างตัวแบบจำแนกว่าสินค้าแต่ละรายการ
ถูกส่งออกทาง **อากาศ บก หรือเรือ** เพื่อสกัดความรู้ที่เดิมอยู่ในประสบการณ์ของเจ้าหน้าที่
ออกมาเป็นกฎที่อ่านและตรวจสอบได้

| หัวข้อ | ค่า |
|---|---|
| ข้อมูลที่ใช้วิเคราะห์ | 1,572,358 รายการ |
| ช่วงเวลา | พ.ศ. 2563–2567 (60 เดือน) |
| ประเทศปลายทาง | 197 ประเทศ |
| ตัวแบบที่เลือก | Decision Tree |
| ความถูกต้อง | 99.28% (Stratified 10-fold Cross Validation) |
| กฎที่สกัดได้ | 92 กฎ |

ตัวแบบที่เปรียบเทียบ: Decision Tree 99.28% · Random Forest 99.27% · Gradient Boosted Trees 99.13%
ทั้งสามตัวต่างกันไม่เกิน 0.15 จุด จึงเลือก Decision Tree ด้วยเกณฑ์การนำไปใช้งานจริง —
ให้กฎ ถ้า–แล้ว ที่ตรวจสอบย้อนได้ และใช้เวลาเทรนน้อยที่สุด

## วิธีนำขึ้น GitHub Pages

1. สร้างที่เก็บใหม่บน GitHub (ตั้งเป็น **Public** ไม่งั้น Pages ใช้ไม่ได้ในบัญชีฟรี)
2. อัปโหลดไฟล์ทั้งหมดนี้ไว้ที่ **ราก** ของที่เก็บ (`index.html` ต้องอยู่ชั้นนอกสุด)
3. ไปที่ **Settings → Pages**
4. หัวข้อ *Build and deployment* เลือก **Deploy from a branch**
   แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` → กด **Save**
5. รอประมาณ 1–2 นาที แล้วกดลิงก์ที่ขึ้นมาด้านบนของหน้านั้น

เสร็จแล้วลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/<ชื่อที่เก็บ>/`
กดแล้วขึ้นหน้าเว็บทันที ไม่ต้องดาวน์โหลดอะไร

> ถ้าเปิดแล้วขึ้น 404 ให้เช็กว่าไฟล์ชื่อ `index.html` ตัวพิมพ์เล็กทั้งหมด และอยู่ที่รากของที่เก็บจริง
